Cart Court · setup

Swear in the court

Four steps. Step 1 is all you need to try it; steps 2–3 put it on real phones.
Open the demo →

1 Gemini (the court's voice) checking…

Sign in with your Google account at aistudio.google.com/apikey, click Create API key, and paste it here. It's free. No key? The court still works in rules mode: the verdicts, prices and demo buttons need no AI.

2 Photon (a real iMessage number) optional checking…

At app.photon.codes, create a project and copy its Project ID and Project Secret.

3 Your household needs step 2 to text

Enter each person's name and the phone number (or iMessage email) they'll text from. When they text the court it already knows who they are, and Text everyone sends each person a personal welcome so they get the court's number.

  1. On Photon's free plan, every number must also be added under Users in the Photon dashboard.
  2. Not sure which handle an iPhone sends from? Open debug.photon.codes on that phone.

Names and numbers are saved only on this computer (data/household.local.json, gitignored). Phones, prices and promos stay synthetic.

4 Make links open on phones optional

The court texts a link to the live case file. For that link to open on a phone, give this computer a public URL. In a second terminal run npm run tunnel, then open the https://…trycloudflare.com address it prints once in your browser. The court picks it up automatically.

Keys are saved only to .env on this computer (it's in .gitignore). This page only works on localhost.
